# Offline structured v5 开发实验

日期：2026-09-29。结论：`offline_structured_v5` 保持为默认关闭的候选策略；它通过了本轮打开式开发集，但尚未通过盲测和 promotion gate。

## 问题与实现

v4 在带数值组合、明确表号、错误论断中的对立条件，以及跨多个 passage 的限定信息上容易返回相关但不充分的证据。v5 保留 v4 的冻结词表和行为，并仅在显式选择新策略时增加：

- 数值组合通道，以及 0–20 的数字/英文数字词等价形式；
- 中文或英文的 Table/Figure 编号通道，对页首的目标表图编号加有限排序权重；
- 用于核验错误论断的双向条件词，例如 union/intersection 和 higher/lower；
- 术语覆盖与小幅前页 tie-break；
- 对材料密集问题优先保留最佳候选所在页的有界窗口，再利用剩余字符预算补入其他候选。

所有通道仍是本地 SQLite FTS 词法检索，不联网、不调用翻译模型。`query_plan` 保存实际通道、数字、别名、表图引用和候选数。返回证据仍受最多 6 段、6000 字符约束。

## 冻结子集与离线结果

本轮先从 Round 2 打开式开发集冻结 15 条：5 条旧证据不充分目标（Q14、Q17、Q18、Q33、Q37）和 10 条对照（Q01、Q03、Q08、Q15、Q21、Q23、Q26、Q29、Q34、Q36）。源 benchmark SHA-256 为 `0e87c71441b11070ee2716918576e03492c39271eaa7c98a4738a14a3fafb5a7`。规则诊断期间未向检索器提供 gold 页或 anchor；评分在每轮检索完成后进行。

| 查询输入 | 策略 | gold 页 | 完整 anchor | 目标 anchor | 对照 anchor |
|---|---|---:|---:|---:|---:|
| 原问题 | v4 | 12/15 | 9/15 | 1/5 | 8/10 |
| 论断 | v4 | 12/15 | 7/15 | 2/5 | 5/10 |
| 原问题 + 论断 | v4 | 12/15 | 9/15 | 1/5 | 8/10 |
| 论断 | v5 最终候选 | **15/15** | **15/15** | **5/5** | **10/10** |

这些结果说明数值、表号、对立条件和页级材料打包确实修复了本轮观察到的失败类型。15 条全部来自已经打开并用于诊断的开发论文，因此 15/15 只能证明实现修复了已知问题，不能估计跨论文泛化能力。

## GPT-5.6-sol 语义核验

离线门槛通过后，使用 `openai_compatible` provider、`gpt-5.6-sol`、`reasoning_effort=medium` 对同一组最终证据运行一次语义核验。gold 未发送给模型。

| 指标 | 结果 |
|---|---:|
| 请求 | 15 |
| 有效结构化结果 | 14/15 |
| 有效结果中的正确判断 | 14/14 |
| 严格端到端完成且正确 | 14/15（93.3%） |
| supported | 8/8 正确 |
| contradicted | 6/6 正确 |
| 有效请求输入 token | 115,082 |
| 有效请求输出 token | 15,817 |
| 有效请求延迟中位数 | 7.805 秒 |
| 有效请求延迟 p95 / 最大值 | 10.818 / 13.286 秒 |

Q18 在主运行和一次单独重试中都返回 `invalid_model_output`。CiteFabric 按策略保守弃权，没有把无效结构当作支持。由于兼容服务没有保留可审计的原始无效响应，当前不能判定是 JSON Schema 兼容、字段约束还是模型输出内容导致。该项计为端到端失败，不能用“14/14”掩盖。

## 决策与下一门槛

v5 不替换默认 v2，也不进入 promotion。下一轮必须冻结规则，在未参与开发的新论文上盲测。promotion 数据量仍按既定协议累计到至少 12–15 篇论文、100–150 条 intent，并分别报告：完整证据充分率、错误论断的 harmful mismatch、逐论文最差表现、6000 字符预算合规性，以及 verifier 的无效结构率。Q18 的重复结构失败需要在盲测前增加脱敏原始响应诊断，且不得自动放宽确定性校验。

本地复放产物位于 `output/validation/evidence_sufficiency_v1/`；该目录不是发布基准，原始模型输出和本地数据库不提交到仓库。
