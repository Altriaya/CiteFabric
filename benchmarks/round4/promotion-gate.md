# structured_v3 默认升级门槛

版本 0.1-draft。以下是拟预注册的产品验收阈值，不是已被实验支持的结论。Pilot 可据标注成本和风险估计修订一次；修订必须在最终候选和最终留出查询冻结前记录。不得看到留出成绩后放宽。

## G0：评测资格

- Round 4 累计至少 **15 个新 paper families、150 个独立 intents**，旧六篇不计入新增规模。15/150 是本方案对“12–15 / 100–150”的保守固定下限，不是统计充分性的保证。
- 其中最终留出至少 **8 个新 paper families、80 个 intents**，均未用于候选开发；至少四个研究领域，各领域至少两篇。Pilot/开发/留出按 family 不重叠。
- 最终留出每篇贡献 8–12 个独立 intents。中英文、预算重复、条件变体均不增加 intent 计数。
- 最终留出至少 50 个 answerable（其中至少 15 个 contradicted）及 20 个 insufficient；至少 20 个表格/数值关系、20 个范围/限定类、20 个条件反例。类别可重叠，但须公布交叉分布。复杂版式或提取困难至少涉及两篇，层别在运行前确定。
- 满足协议隔离、双语等价复核、双人标注/盲评和冻结记录。无独立复核或未封存 gold，则只算开发/自审结果，不能 promotion。

若 pilot 只有 4 篇/60 intents，加上最小留出仍未达到累计下限，须补充开发或留出语料。补样规则和总量须在最终运行前冻结，不能不断补到显著为止。

## G1：证据完整性与兼容性（硬门槛）

返回证据 100% 可回放；跨论文/版本错误绑定为 0；预算越界为 0；迁移备份、旧证据与回执可读性、取消/降级、SDK/CLI/MCP 契约检查全部通过。Linux/macOS/Windows CI 通过。任一失败阻止默认升级。

## G2：独立留出质量（全部满足）

主预算 6000 字符、中英文各自单独判定：

| 指标 | 拟定门槛 |
| --- | --- |
| 论文等权 answerable ESR | v3 ≥85% |
| v3 − v2 配对 ESR | 点估计 ≥+5 个百分点，按论文聚类的双侧 95% 区间下界 >0 |
| 限定句保留率 | v3 ≥90%，且不低于 v2 |
| 条件反例 harmful_mismatch | v3 ≤5%，且不高于 v2；同时公布错误数和区间，不宣称真实错误率已被证明低于 5% |
| 单篇和关键层退步 | 不得比 v2 低超过 10 个百分点；公布每篇、领域、题型及负例层结果，缺足够样本的层标“不足以判断” |

绝对质量和配对改进同时要求；若 v2 已接近满分而不可能达到 +5pp，本次仍不能按该规则升级，应在新的预注册轮次提出不同假设，不能事后改用相对误差下降。

小样本下零错误的上界仍可能很宽，8 个留出论文也可能无法排除无改进。规模下限达到而区间不通过时，结论是“升级证据不足”，不是强行通过或自动判定算法无价值。这里的区间用于候选比较，不提供普适安全认证。

## G3：运行与响应成本

- 同硬件交错测试的热检索 p95 ≤v2 的 1.5 倍；冷索引耗时单列，所有调用遵守产品配置的 timeout 及明确降级。
- 在不损失 G2 质量的前提下，完整初始 MCP 响应平均 UTF-8 字节 ≤v2 的 1.15 倍。若公开 trace 资源，完整审计读取路径的平均字节也 ≤v2 等价审计路径的 1.15 倍。
- 报告原文字数、对象数、初始响应字节、审计总字节各自变化。尚未实测 tokenizer 时 token 成本标未测；本 gate 不采用推算 token。

## 决策记录

每次判定记录协议/算法/fixture/gold/run 哈希、各 gate 的 pass/fail/inconclusive、审阅者和理由。只有所有 gate 通过才允许改默认值；成功后的发布仍保留显式 `v2` 选择和回退说明。

默认升级与 semantic verifier 是两个交付决策。Verifier 的接口设计可提前开展；其效果验证和默认启用必须另有封存的 claim 标签、错误类型与拒答门槛，不能复用检索 ESR 当语义准确率。
